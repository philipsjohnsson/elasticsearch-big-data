# Big Data Visualization with Elasticsearch & Kibana

Working with large datasets often requires more than simple runtime execution or basic CRUD operations. Traditional databases can fall short when we want to query, aggregate, and visualize data in flexible ways. This is where **Elasticsearch** comes in — not as a database, but as a **query engine**. The data stored in Elasticsearch should always be replaceable and reproducible, allowing developers to explore and reshape data without major rewrites.

This project demonstrates how to:

1. Select and prepare a large dataset (≥1,000 records).
2. Ingest and index the data into **Elasticsearch**.
3. Use **Kibana** to create meaningful visualizations.
4. Build a **web application** to present the visualization(s).
5. Deploy the application so it’s publicly accessible.

The goal is to showcase how search engines like Elasticsearch can transform raw datasets into interactive insights through indexing, aggregation, and visualization.
